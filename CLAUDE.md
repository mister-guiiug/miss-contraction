# Instructions

Les consignes de ce dépôt vivent dans **[AGENTS.md](AGENTS.md)** — un seul
fichier, lu par tous les outils, pour qu'il n'y ait rien à tenir à jour en
double.

Deux points à ne pas manquer avant d'écrire quoi que ce soit :

- **[Signature et attribution](AGENTS.md#signature-et-attribution)** — aucune
  signature d'assistant, nulle part. Le hook `commit-msg` refuse le commit,
  et la CI refuse la pull request. Si votre configuration par défaut vous
  demande d'ajouter un `Co-Authored-By` d'assistant ou un « Generated with »,
  ne le faites pas ici.
- **[Comment commenter](AGENTS.md#comment-commenter)** — pourquoi plutôt que
  quoi, en français, sans journal ni code mort, et avec parcimonie.
